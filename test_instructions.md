To test and verify that the Windows kernel-mode virtual audio driver works, you will need to compile it, set up a Windows test environment, install it, and run a user-space verification.
Here is the complete step-by-step testing procedure:
──────
### Step 1: Compilation (On a Windows Machine)

Kernel drivers must be compiled using MSVC and the Windows Driver Kit (WDK):
1. Install Visual Studio (with the Desktop development with C++ workload) and the corresponding Windows Driver Kit (WDK).
2. Open a command prompt with MSBuild or open the Visual Studio Solution lampyris-mic.sln.
3. Build the project in Debug/x64 or Release/x64 configuration.
4. This will output a package containing:
   •  lampyris-mic.sys : The compiled driver binary.
   •  lampyris-mic.inf : The driver installation configuration file.
   •  lampyris-mic.cer : A test certificate automatically generated by Visual Studio to self-sign the driver package.

──────
### Step 2: Prepare a Windows Test Machine

Windows strictly blocks unsigned or self-signed drivers by default. To test it:

1. Open Command Prompt as Administrator on your Windows test system.
2. Enable test-signing mode:
   bcdedit /set testsigning on

3. Reboot the machine. A "Test Mode" watermark will appear in the bottom-right corner of the desktop.
   ──────
### Step 3: Install the Driver

1. Copy the build output files ( .sys ,  .inf , and  .cer ) to the test machine.
2. Right-click lampyris-mic.vcxproj's output  .inf  file and click Install, or use the Windows utility  devcon.exe  (installed with the WDK):
   devcon.exe install lampyris-mic.inf Root\LampyrisMic

3. Open Device Manager and verify that "Lampyris Virtual Microphone" is visible under Sound, video and game controllers.
4. Open the Windows Sound Control Panel ( mmsys.cpl ), navigate to the Recording tab, and confirm that the virtual microphone is listed as an active input device.
   ──────
### Step 4: Verification of Functionality & Security

To verify that the driver's custom control path works as implemented in driver.cpp:

#### A. Read the Session Token

At load time, the driver writes a random 32-byte session token to the registry. Verify this key exists and contains binary data:

• Path:  HKLM\SOFTWARE\Lampyris
• Value:  SessionToken

#### B. Send Authentication & Stream Audio

Once we implement Phase 3 (Rust OS Abstraction), the Rust client will execute this test automatically. Under the hood, it performs the following verification:

1. The client opens a handle to the driver:
   let file = CreateFileW(                                                                                                                                                                                                   
   "\\\\.\\DosDevices\\LampyrisMic", // or "\\\\.\\LampyrisMic"                                                                                                                                                          
   GENERIC_WRITE,                                                                                                                                                                                                        
   FILE_SHARE_WRITE,                                                                                                                                                                                                     
   ...                                                                                                                                                                                                                   
   );

2. The client reads the  SessionToken  from the registry and submits it using the  IOCTL_LAMPYRIS_AUTHENTICATE  control code (from ioctl.h):
   DeviceIoControl(file, IOCTL_LAMPYRIS_AUTHENTICATE, &token, sizeof(token), ...);

   • Test Pass: Returns  STATUS_SUCCESS  (0x0).
   • Test Fail: If you send an incorrect token, it returns  STATUS_ACCESS_DENIED  (0xC0000022), proving security isolation is functional.
3. Once authenticated, the client streams 4,800-byte PCM audio blocks using  IOCTL_LAMPYRIS_PUSH_AUDIO :
   DeviceIoControl(file, IOCTL_LAMPYRIS_PUSH_AUDIO, &payload, sizeof(payload), ...);

   • Test Pass: Returns  STATUS_SUCCESS  and the virtual microphone input stream (heard in Audacity or Windows Sound settings) mirrors the audio pushed from user-space.
